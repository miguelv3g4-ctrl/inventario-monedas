Conectar para editar

Cualquiera con el link puede ver el inventario. Para poner datos y fotos hace falta una llave de GitHub, que se guarda solo en este navegador.

  1. Abre github.com → Settings → Fine-grained tokens → Generate new token.
  2. En Repository access elige Only select repositories y marca solo el repositorio del inventario.
  3. En Permissions → Repository → Contents pon Read and write. Genera la llave y pégala aquí.
